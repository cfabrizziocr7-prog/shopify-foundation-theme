# Sloane shot workflow
1. Choose one concept and record its ID, hypothesis and version in creative/sloane-concepts.json.
2. Attach actual front, back and detail images. Record reference filenames; do not treat textual description as an identity lock.
3. Generate a still first when changing location/model. Check collar, zip, pockets/panels, cuffs, texture, gray tone and cropped proportions against originals.
4. For each approved still, request one 4–5 second image-to-video shot. Action: adult model turns a quarter toward the window; camera: locked medium framing. Keep hands away from zipper unless the action is essential. No text; no claimed testimonial.
5. Use the same model/outfit/light for connected shots. Identify source clip, usable in/out seconds, camera and garment state in the shot manifest. Trim keeper ranges locally with media.cjs.
6. Assemble using the existing Remotion template, replacing stills with approved clips. Add product name, concise hook and one CTA as editable text. Align captions to recorded speech, not estimated script timing.
7. Export 1080x1920 H.264. Inspect metadata, one-second samples and every transition; review all frames around any detected defect. Record visual QA separately from technical checks.
8. Prepare local platform drafts. Confirm destination, rights, current price/stock, store launch readiness, and explicit publish approval. Schedule only after approval through Metricool.
9. Use actual platform retention and Shopify funnel data to decide the next revision. Change one variable per controlled comparison.

Higgsfield website is preferred for approved Unlimited use; no automatic API submissions. Model names and plan limits are checked at generation time. Asset exports remain pending until a generation path and budget are authorized.
